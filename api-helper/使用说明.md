# 接口助手

选择语音识别和记忆模型。适配当前朝比奈真冬桌宠的插件接口 v1。

## 安装

1. 解压 `接口助手_1.0.0.zip`，得到 `api-helper` 文件夹。
2. 右键桌宠 → 插件 → 插件管理 → **打开插件文件夹**。
3. 把整个 `api-helper` 文件夹复制进去。正确结构是 `plugins/api-helper/plugin.json`。
4. 回到插件管理，刷新列表，启用“接口助手”。
5. 右键桌宠 → 插件 → **接口助手…**，配置接口。

以你正在使用的那份桌宠打开的插件目录为准，不需要覆盖 `resources/app`，也不需要替换 exe。初次使用时，两项“使用插件设置”均关闭；只开启你需要的项目。

## 语音识别

负责把你说的话转成文字。配音仍使用桌宠原来的设置。

| 平台 | 内置候选 | 接入方式 |
| --- | --- | --- |
| 阿里云 | `qwen3-asr-flash` | 音频 Data URI → 兼容接口 `chat/completions` |
| 硅基流动 | `FunAudioLLM/SenseVoiceSmall`、`TeleAI/TeleSpeechASR` | 文件 → `audio/transcriptions` |
| 其他兼容接口 | 自行填写 | 文件 → `audio/transcriptions` |

选择平台、填该平台密钥，勾选“使用插件设置”，再点“保存并应用”。阿里云需开通所选模型，密钥、业务空间和地址的地域须一致。地址框填到 `/compatible-mode/v1` 即可；也支持完整的 `/chat/completions` 地址。

阿里云预设使用北京兼容域名。若控制台提供业务空间专属地址，可改成 `https://你的业务空间ID.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`；新加坡使用控制台对应地域的地址。请把占位文字换成真实 ID。

“自动”不传语言参数，适合中日英混合说话。“测试识别”发送半秒静音，只检查请求和返回格式；实际识别效果请在语音通话中确认。此适配支持 `qwen3-asr-flash` 及日期版本，其他实时识别、异步长录音模型需要另一种接法。

## 记忆向量

| 平台 | 内置候选 |
| --- | --- |
| 硅基流动 | BGE-M3、Pro/BGE-M3、Qwen3-Embedding 0.6B / 4B / 8B |
| 阿里云 | `qwen3.7-text-embedding-flash`、`qwen3.7-text-embedding`、`text-embedding-v4` |
| 智谱 | `embedding-3` |
| 其他兼容接口 / 本地 | 自行填写，例如本地服务已加载的向量模型 |

点 **选择模型** 可选内置候选，也可点 **读取平台模型列表**。部分服务没有模型列表接口，插件会保留内置候选；输入框始终支持手动填写。候选列表不代表账号已开通全部模型。

填完配置后，先“测试向量”，再勾选“使用插件设置”并保存。桌宠原设置中的“长期记忆”也要开启；召回条数和相关度门槛继续使用原设置。插件会按不同平台的单批上限拆分请求。

**首次用插件接管记忆，或切换平台、地址、模型后，请点“重算全部记忆”。** 插件给每套配置使用独立的向量标记，避免不同向量混在一起，即使模型名称相同也需要检查是否重算。仅更换同一接口的密钥不需要重算。

重算可能计费，条目多时需要等待。重算前先在插件数据目录保存 `memory-before-rebuild.json`，包含当时磁盘上的记忆文字和向量；再次重算会更新这份备份。“打开备份位置”可以找到它。重算失败会显示原因，文字会保留；已经完成的批次可能已在内存中更新，可排除接口问题后再次重算。

## 保存、停用与恢复

- 密钥单独保存在当前桌宠数据目录的 `plugin-data/api-helper.json` 中，采用本地 JSON 明文存储。插件不会自动复制桌宠原设置的密钥；同一平台用于两项功能时，请分别填写。
- 已存密钥在输入框中留空表示不变；点“清除”后保存才会清除。切换平台会清空待保存密钥，避免把旧平台密钥发给新平台。远程服务需要密钥，本机回环地址允许留空。
- 开启接管后，相关平台、模型、密钥和测试请在本插件面板管理；桌宠原设置页仍显示原配置。
- 关闭某项“使用插件设置”并保存，会恢复该项原接口；停用插件会恢复两项原接口。挂断通话、改配置、停用插件时会取消插件正在处理的请求。
- **恢复接口不会自动把向量恢复成旧模型。** 如果已经用插件重算或新增记忆，停用后请在桌宠原记忆管理里用原模型重新计算。插件不自动覆盖记忆文件，以免丢掉安装后新增的文字。
- 需要从备份恢复时，先退出桌宠并另存当前 `memory.json`，再将需要的备份复制回当前数据目录，改名为 `memory.json`。恢复旧备份会回到备份时的记忆内容。

## 兼容范围

针对目前这份真冬桌宠的记忆模块和通话入口适配。插件接口 v1 没有公开的语音或向量替换钩子，因此插件使用有兼容检查的运行时桥接；停用时撤销替换，不修改桌宠源码。其他桌宠和后续大改版本需要另行验证。若显示“启用失败”，查看插件日志中的具体原因，不要直接覆盖桌宠文件。
