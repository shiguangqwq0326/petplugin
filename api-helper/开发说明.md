# 接口助手开发说明

名称：接口助手。描述：选择语音识别和记忆模型。

采用用户提供的《桌宠插件接口说明 v1》。无 npm 依赖、无宿主源码补丁；只声明适用于 `mafuyu-desktop-pet`。

| 文件 | 作用 |
| --- | --- |
| `plugin.json` | 插件清单和适用桌宠 |
| `main.js` | 生命周期、独立配置、插件面板 IPC、测试、备份与重算 |
| `host-adapter.js` | 校验宿主、接管/恢复 ASR 与 Memory、取消通话、区分向量空间 |
| `catalog.js` | 平台地址、内置模型、配置校验、单批上限 |
| `client.js` | HTTP 请求、ASR 协议转换、向量校验、模型列表、取消与超时 |
| `renderer.js` | 同步页面内识别可用标志；卸载还原 |
| `panel.html / panel.js / panel.css` | 配置页面和模型选择按钮 |

## 为什么需要兼容桥

v1 公开 API 提供菜单、插件面板、存储、事件和 renderer 消息，没有 ASR 或 embedding 服务替换接口。不能只靠 `chat:*` 事件实现：语音通话也不经过这些事件。

桥接先确认应用 ID、已缓存主模块的 `_test.memory()`、当前数据目录和两个 IPC 处理函数；不会 `require` 并重新执行宿主主入口。任何关键入口缺失都会拒绝启用。宿主代码仍保留原样。

1. `call-asr`：从 Electron `_invokeHandlers` 捕获原函数，用 `removeHandler/handle` 临时注册包装函数。插件关闭语音接管时直接委托原函数。支持宿主通话编号和 `call-cancel` 前缀取消。
2. `get-settings`：仅在插件 ASR 配置可用时将返回副本的 `hasAsr` 标为 true。通过插件 renderer 消息补回页面标志，并在宿主设置广播之后再次同步。
3. `Memory.cfg/embed`：临时覆盖当前实例的方法；保留原来的启用开关、召回阈值、条数、文件位置和其他行为。HTTP 使用用户选择的真实模型名，存储/检索使用 `模型名@api-helper:哈希`，哈希包括平台、地址和模型，不包括密钥。
4. 卸载：取消请求，清理事件，还原仍属于本插件的处理函数与方法。另一个插件后来替换的入口不会被本插件覆盖。宿主 renderer 原有的“一次性语音错误提示”代码没有修改。

`_invokeHandlers` 和 `_test.memory()` 属于当前实现的内部入口，不能承诺对未来版本稳定；这是兼容桥的明确限制。[Electron 官方实现](https://github.com/electron/electron/blob/main/lib/browser/ipc-main-impl.ts) 可用于核对注册行为。

## 数据与网络

- 启用插件本身不发送测试、模型列表或重算请求。面板内的读取、测试、重算由用户点击；启用具体接口后，正常通话与记忆请求按所存配置发送。
- 所有接口请求都在主进程执行；面板 CSP 不允许页面联网，面板不拿回已存密钥。插件存储采用宿主 v1 的 JSON 存储。
- 不借用聊天、语音识别或其他插件的密钥。每项配置各自保存一个密钥。
- 向量回复要求数量、序号、维度、数值和范数有效，再归一化为 `Float32Array`。同一次 embed 的所有批次通过才向调用方返回。
- 重算调用宿主现有 `Memory.reembed()`，宿主以批次更新内存，最后保存。不是整个数据库的事务；失败不会删除文字，也不会自动用旧备份覆盖当前记忆。
- 备份仅覆盖最近一次插件面板发起的重算；从桌宠原页面发起的重算不经过插件备份按钮逻辑。

## 验证

工作区中的 `../tests/api-helper-check.cjs` 使用真实宿主 Memory 和 PluginManager、模拟 Electron/DOM/网络。检查安装发现、启停重载、面板 IPC、模型选择、平台切换、密钥处理、ASR 数据、拆包、坏向量、备份重算、取消恢复及宿主文件哈希。

离线检查不能代替账号权限、实际录音和在线模型质量验证。安装后应填自己的密钥执行面板测试，再进行一次实际通话。
