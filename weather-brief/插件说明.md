# 今日天气 · 插件说明

一个给桌宠用的天气插件：第一次问天气时它会问你在哪座城市，之后你只要说「今天天气怎么样」，它就用一句话告诉你**今天天气、要不要带伞、还需要注意什么**。

- 插件名称：今日天气
- 插件 ID：`weather-brief`
- 版本：1.0.1
- 接口版本：v1
- 适用桌宠：宵崎奏、青柳冬弥、朝比奈真冬、晓山瑞希（`pets: ["*"]`）
- 是否需要 API 密钥：不需要
- 天气数据：Open-Meteo（<https://open-meteo.com>）

---

## 一、能做什么

| 场景 | 桌宠的反应 |
| --- | --- |
| 第一次问天气 | 反问你所在的城市，并把城市记下来 |
| 之后问「今天天气怎么样」 | 查询当天天气，用一句话回答 |
| 查询成功 | 天气 + 要不要带伞 + 需要注意的事，合成一句话 |
| 查询失败（断网、接口报错等） | 最终回答「我没有办法看到你所在地的天气」 |
| 城市名打错 | 不会报失败，而是请你换个说法再说一次 |

回答示例：

> 杭州今天有小雨，12~21℃，记得带伞；雨势不小，尽量避开积水路段。

> 杭州今天晴，5~18℃，不用带伞；紫外线很强，记得防晒。

> 杭州今天阴，12~21℃，不用带伞；没什么要特别注意的。

只回答**今天**的天气；问到明天、后天、周末时插件不会插手，交给桌宠自己的模型回答。

## 二、安装

> 开发完成后没有自动安装，需要手动放进桌宠的插件文件夹。

1. 右键桌宠（或通知区域图标）→ **插件** → **插件管理…**
2. 点 **打开插件文件夹**。
3. 把整个 `weather-brief` 文件夹复制进去，保证目录结构是：

   ```
   plugins\
     weather-brief\
       plugin.json
       main.js
       插件说明.md
   ```

4. 回到插件管理，点 **刷新列表**，打开「今日天气」右侧的开关。
5. 以后改了代码，点 **重新加载** 即可，不用重启桌宠。

不同桌宠的插件文件夹：

| 桌宠 | 插件文件夹 |
| --- | --- |
| 宵崎奏 | `%APPDATA%\kanade-desktop-pet\plugins` |
| 青柳冬弥 | `%APPDATA%\toya-desktop-pet\plugins` |
| 朝比奈真冬 | `%APPDATA%\真冬桌宠\plugins`（以插件管理里「打开插件文件夹」为准） |
| 晓山瑞希 | `%APPDATA%\mizuki-desktop-pet\plugins` |

## 三、第一次使用

1. 在聊天框里问：

   > 今天天气怎么样

2. 桌宠会回答：

   > 你所在的城市是哪里？告诉我城市名就好，比如「杭州」。

3. 直接输入城市名，例如：

   > 杭州

   也可以说得自然一点：「我在杭州」「我住在上海市浦东新区」「坐标杭州」。插件会自己整理出城市名。

4. 桌宠确认：

   > 记住了，你在杭州（浙江）。以后问我「今天天气怎么样」就好。

5. 再问一次「今天天气怎么样」，就会得到天气答案。

如果城市名打错了，桌宠会说「我没找到『xxx』这个地方，能换个说法吗？」，你重新输入即可；说「算了」「不用了」可以取消这次设置。

## 四、日常使用

### 直接说话

下面这些说法都能触发查询：

- 今天天气怎么样 / 今天天气如何 / 今天天气
- 天气怎么样 / 天气如何
- 今天会下雨吗 / 今天要带伞吗 / 今天用不用带伞
- 外面冷不冷 / 今天热不热 / 今天晒不晒
- 现在气温多少 / 今天几度

普通聊天（例如「今天天气不错」「我不喜欢下雨天」）不会被拦截。

### 聊天指令

| 指令 | 作用 |
| --- | --- |
| `/天气` | 查询已保存城市的天气 |
| `/天气 杭州` | 临时查另一个城市，不会改掉已保存的城市 |
| `/城市 杭州` | 设置 / 更换所在城市 |
| `/设置城市 杭州` | 同上 |
| `/所在地 杭州` | 同上 |

### 右键菜单

右键桌宠 → **插件**：

| 菜单项 | 作用 |
| --- | --- |
| 现在天气怎么样 | 立即查一次，不需要打字 |
| 设置所在城市… | 打开聊天框，等你输入城市名 |
| 查看当前城市 | 告诉你现在记住的是哪座城市 |
| 清除城市设置 | 忘掉当前城市，下次问天气时重新询问 |

## 五、回答是怎么拼出来的

查询使用 Open-Meteo 的免费接口，不需要注册，也不需要填密钥。

一句话由三部分组成：

1. **今天天气**：按 WMO 天气代码翻译成「晴 / 多云 / 阴 / 小雨 / 雷阵雨 / 小雪 / 有雾」等说法，并给出当天最低~最高气温。
2. **要不要带伞**：
   - 有雨、有雪，或降雨概率 ≥ 50%，或降水量 ≥ 1 mm →「记得带伞」
   - 降雨概率 30%~49% →「最好带把伞」
   - 其他 →「不用带伞」
3. **额外注意**：按优先级取一条最值得提醒的：
   - 雷雨、冻雨、下雪、大雨积水
   - 有雾、紫外线偏强 / 很强
   - 高温（≥ 35℃）、低温（≤ 0℃）
   - 大风、早晚温差大（≥ 12℃）
   - 都没有 →「没什么要特别注意的」

同一座城市的结果会缓存 10 分钟，避免短时间反复请求接口。

### 响应速度

桌宠的聊天拦截最多只等 1.5 秒。插件的处理方式是：

- 1 秒内查到（命中缓存，或接口较快）→ 直接把一句话作为回答发出；
- 超过 1 秒 → 先回一句「我看看今天的天气……」，查到后再用气泡补上完整答案，不会卡住聊天。

## 六、查询失败时

以下情况都会返回同一句话：

> 我没有办法看到你所在地的天气

包括：断网、请求超时（6 秒）、接口返回错误、返回的数据缺少温度或天气代码、经纬度无效等。

注意：**城市名找不到**不算查询失败。插件会提示「我没找到『xxx』这个地方」，并继续等你输入正确的城市名，避免因为打错字就得到一句冷冰冰的失败台词。

## 七、数据与隐私

- 只保存城市名、省份、国家、经纬度，保存在桌宠数据目录的 `plugin-data\weather-brief.json` 里。
- 不读取聊天记录，不保存提问内容，不需要任何 API 密钥。
- 联网时只向 `open-meteo.com` 发送城市名（首次定位时）和经纬度并取回天气数据，不发送桌宠设置或聊天内容。
- 停用插件不会删除已保存的城市；如需彻底清理，删除桌宠数据目录下的 `plugin-data\weather-brief.json` 即可。

---

## 八、文件结构

```
weather-brief\
  plugin.json     清单：id、名称、版本、入口、适用桌宠
  main.js         全部逻辑：聊天识别、城市设置、天气查询、一句话生成、菜单
  插件说明.md      本文档
```

`main.js` 只使用 Node 自带的 `fetch`、`URL`、`AbortController`，没有第三方依赖，复制文件夹即可使用。

## 九、排查问题

1. 插件管理卡片显示「不可用」：确认 `plugin.json` 和 `main.js` 都在文件夹根目录，且 `plugin.json` 是合法 JSON。
2. 问天气没反应：确认插件开关是打开的；再说一次「今天天气怎么样」，或直接点菜单「现在天气怎么样」。
3. 一直回答「我没有办法看到你所在地的天气」：检查电脑能不能访问 `api.open-meteo.com` 和 `geocoding-api.open-meteo.com`；公司网络、代理或防火墙可能拦截。
4. 城市一直找不到：换用更常见的写法，例如「杭州」而不是「杭州市西湖区文三路」；国外城市可以试英文名，例如 `Tokyo`。
5. 想看详细原因：插件管理 → **插件日志**，或数据目录下的 `plugins.log`，搜索 `[weather-brief]`。

## 十、限制

- 只查今天，不查明天、逐小时、空气质量或台风路径。
- 依赖 Open-Meteo 的免费服务，接口不可用时只能返回失败台词；它适合日常提醒，不适合作为出行决策的唯一依据。
- 城市按名称查询，插件会同时尝试「厦门」和「厦门市」两种写法，再按人口和行政级别挑选最像城市的结果；极小地名、重名乡镇仍可能定位到上一级城市。
- 桌宠本身没有配置聊天模型也能用，因为回答完全由插件生成。
